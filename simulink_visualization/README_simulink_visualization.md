# IEEE 33-Bus Smart Inverter Simulink Visualization

## Purpose

`IEEE33bus_SmartInverter_Hybrid_PSO.slx` is a professional thesis and presentation diagram for the project:

> Optimized Smart Inverter Control for Voltage Regulation in High PV Penetration Distribution Networks

The wide landscape model presents the complete workflow:

`IEEE 33-bus feeder -> PV generation -> smart inverter -> Volt-VAR / Volt-Watt / Hybrid control -> PSO optimization -> measurements -> performance indices -> results`

## Visualization Model Versus EMT Model

This Simulink model is intentionally lightweight. It explains the architecture and connects the major research stages without reproducing semiconductor switching, detailed PWM, electromagnetic transients, protection dynamics, or an unbalanced three-phase Simscape feeder.

This Simulink file is a high-level workflow visualization and quasi-static analysis interface. It is not a detailed EMT switching-level inverter model. The numerical results are generated by the MATLAB load-flow and smart inverter control scripts.

## MATLAB Result Script Integration

The orange `Run MATLAB Engine` launcher documents and exposes the main pipeline:

```matlab
main_generate_final_results
```

The workflow refers to these existing scripts:

- `main_run_all_cases`
- `main_run_stress_cases`
- `run_pso_optimization_v2`
- `analyze_controller_activation`
- `generate_final_report_summary`

PSO is treated as an offline optimization stage. Its optimized curve parameters are then applied by the hybrid smart inverter controller.

## Subsystems

1. **IEEE 33-Bus Distribution Network** shows the radial feeder, slack bus, buses 1-33, weak-end buses, representative loads, and voltage-current measurement.
2. **PV Generation at Selected Buses** shows PV at buses 6, 14, 18, 25, 30, and 33 with MPPT and penetration scenarios.
3. **Smart Inverter - VSI** shows the DC link, three-phase VSI, LCL filter, PLL, reference interface, capability constraint, and output quantities.
4. **Control System - Smart Inverter Control** shows Volt-VAR, Volt-Watt, hybrid control, mode selection, and PSO parameter optimization.
5. **Measurements and Outputs** shows recorded voltage, current, power, loss, curtailment, and activation data.
6. **Results and Analysis** shows the MATLAB-generated plots, comparisons, hosting capacity, PSO convergence, and dashboard.
7. **Simulation Scenarios** shows PV penetration, control modes, and irradiance-load conditions.
8. **Performance Indices** shows voltage, loss, curtailment, hosting capacity, recovery, objective-function, and saved-report metrics.

## Limitations

The diagram is a thesis-facing workflow visualization. It is not intended to run a detailed electrical transient simulation. Use the existing MATLAB load-flow, PV, controller, optimization, metric, plotting, validation, and report scripts for numerical analysis.
